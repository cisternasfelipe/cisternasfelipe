## 🚀 Proyecto destacado

### 🎙️ [VoicePod](https://github.com/cisternasfelipe/voicepod): tu propio "Whisper Flow", gratis

Dictado por voz rápido y privado: hablas, y el texto aparece en cualquier aplicación que estés usando. Es la alternativa gratuita a los servicios de dictado de pago.

- **Local y privado:** el reconocimiento de voz corre en tu computador con Sherpa-ONNX, sin enviar tu audio a ningún servidor.
- **Casi gratis:** solo pagas el pulido opcional con un LLM (vía OpenRouter). Con uso intenso son unos **2.000 pesos al mes**.
- **Texto limpio:** un LLM corrige puntuación y muletillas para que lo dictado quede listo para enviar.
- **Integrado al sistema:** usa hooks de bajo nivel para funcionar en cualquier programa.

`C#` · `.NET` · `Sherpa-ONNX` · `OpenRouter`
