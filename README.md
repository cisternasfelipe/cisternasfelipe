## 🎙️ Código abierto destacado

### [VoicePod](https://github.com/cisternasfelipe/voicepod): dictado por voz gratis, al estilo de Wispr Flow

Hablas y el texto aparece en cualquier aplicación de Windows. Es la alternativa gratuita a los servicios de dictado de pago.

- **Local y privado:** el reconocimiento de voz corre en tu computador con Sherpa-ONNX; tu audio no sale de él.
- **Casi gratis:** solo pagas el pulido opcional con un LLM (vía OpenRouter): unos **2.000 CLP al mes** con uso intenso.
- **Texto limpio:** el LLM corrige puntuación y muletillas para que el texto quede listo para enviar.
- **Integrado al sistema:** usa hooks de bajo nivel para funcionar en cualquier programa.

`C#` · `.NET` · `Sherpa-ONNX` · `OpenRouter`

**Otros:** [swarm-of-agents](https://github.com/cisternasfelipe/swarm-of-agents) (orquestación de agentes de IA) · [Organizate](https://github.com/cisternasfelipe/Organizate) (metas y horas de estudio, TypeScript)
